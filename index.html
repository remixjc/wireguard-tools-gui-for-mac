提权只开一条缝，而且是唯一的一条。

WireGuard Tray 不做任何「万能 sudo」。它只放行两个动作：启动一条配置、关闭一条配置。

仅本机调用，无网络服务应用只在本机执行 wg-quick，不开放端口、不连接云。
命令精确匹配白名单sudoers 仅放行 wg-quick 的 up / down 动作，绝对路径锁定，防止 PATH 劫持。
安装即校验，失败即回滚写入后执行 visudo -c 校验，权限固定 0440 root:wheel。
密钥留在本地隧道私钥仅存在于你的配置文件中，应用不采集、不上传任何数据。
# /etc/sudoers.d/wireguard-tray Defaults secure_path="/opt/homebrew/bin:/usr/bin:/bin:…" %admin ALL=(root) NOPASSWD: /opt/homebrew/Cellar/wireguard-tools/…/wg-quick up *, /opt/homebrew/Cellar/wireguard-tools/…/wg-quick down *

FAQ

开始之前，你可能想知道。

需要先安装什么？+
只需 Homebrew 的 wireguard-tools：brew install wireguard-tools。然后把你的 .conf 配置放进 /opt/homebrew/etc/wireguard 或 /etc/wireguard。
为什么第一次启停要输密码？+
启停隧道需要 root 权限。在设置里执行一次「安装命令」写入 sudoers 白名单后即可全程免密；跳过安装则每次使用管理员授权弹窗，同样安全。
报错 "Version mismatch: bash 3 detected" 怎么办？+
wg-quick 要求 bash 4+，而 macOS 系统自带 bash 是 3.2。应用已自动使用 Homebrew bash（/opt/homebrew/bin/bash）执行，并保证 sudo 与授权弹窗两条路径的 PATH 都正确；如仍报错请确认已安装 bash 4+。
配置放在哪里？+
应用按 wg-quick 的标准顺序搜索：/etc/wireguard → /usr/local/etc/wireguard → /opt/homebrew/etc/wireguard，按名称去重列出，详情窗口可直接打开配置目录。
与应用商店版本有什么区别？+
商店版通常不开放自定义脚本能力。本应用直接管理 Homebrew 的 wg-quick，完整支持 PostUp / PostDown（含 networksetup 代理切换与自定义命令），配置就是你的 .conf 文件。
会联网上传数据吗？+
不会。应用只在本机调用 wg-quick，不开放网络端口、不需要账号、不上传任何配置或流量数据。
